Extra MailPoet blocks for the Gutenberg post editor: Newsletter Archive, Newsletter Embed.

== Installation ==

1. You need to have the MailPoet plugin installed and activated before using this plugin. Send some newsletters so you have content for the blocks.
1. Upload this plugin's files to the `/wp-content/plugins/mailpoet-extra-blocks` directory, or install the plugin through the WordPress plugins screen directly.
1. Activate the plugin through the 'Plugins' screen in WordPress.
1. Use the extra MailPoet blocks in the Gutenberg editor.
